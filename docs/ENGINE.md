# Движки KVS

Формат читается **двумя независимыми движками**, которые обязаны давать
одинаковую картинку (это проверяется тестом `TestCrossEngine`):

| | Python (`kvs/`) | JavaScript (`viewer/kvs-player.js`) |
|---|---|---|
| растеризатор | собственный сканлайн-алгоритм | Canvas2D / Path2D |
| зависимости | **только stdlib** (zlib, lzma, struct, json) | **только браузерные API** (DecompressionStream, DOMMatrix, Path2D) |
| применение | CLI, экспорт PNG/GIF/APNG, серверные превью | интерактивный плеер, drag&drop |
| кривые | аппроксимация полилиниями (допуск 0.15 px) | нативные Безье канваса |

## 1. Пайплайн кадра (Python)

```
.kvs  ──decode──►  компактная сцена
                     │  Renderer.render(frame)
                     ▼
   для каждого слоя (снизу вверх):
     1. каналы трансформа  → матрица M = T·R·S·Skew·T(-a), учёт parent-цепочки
     2. геометрия          → полилинии в локальных координатах
                              (Безье плоско аппроксимируются, морфинг интерполируется)
     3. M применяется к точкам; толщина обводки масштабируется |det M|^½
     4. обводка            → заполняемый аутлайн (offset-полигон: cap/join/dash)
     5. растеризация       → карта покрытия 0..255 (сканлайн + вертикальный
                              суперсэмплинг ss и дробное покрытие крайних пикселей)
     6. покраска           → сплошной цвет или LUT-градиент (256 стопов),
                              координаты градиента возвращаются в локальную
                              систему обратной матрицей M⁻¹
     7. смешивание         → source-over / multiply / screen / overlay / add
```

Ключевые модули:

* `kvs/container.py` — заголовок, CRC, кодеки, превью;
* `kvs/scene.py` — easing-таблица, каналы, компиляция авторинга в компакт;
* `kvs/geometry.py` — матрицы, Безье, примитивы, аутлайн обводки, пунктир;
* `kvs/raster.py` — Framebuffer и сканлайн-покрытие (evenodd / nonzero);
* `kvs/paint.py` — градиенты и LUT;
* `kvs/renderer.py` — сборка кадра, blend'ы, resize/downscale;
* `kvs/png.py`, `kvs/anim.py` — PNG/APNG/GIF **собственными кодерами** (LZW для GIF — тоже свой).

## 2. Скорость

Чистый Python без numpy: кадр 512×512 с десятком слоёв — ~30–120 мс
(`ss=4`). Секвенция из 90 кадров heart'а собирается в GIF за ~70 с на ядро;
`--ss 2` и `--size` уменьшают время в разы. Узкие места честные:
покомпонентное смешивание пикселей и аппроксимация кривых.

## 3. Экспорт

```bash
kvsc export examples/heart.kvs -o out.gif            # GIF (своя LZW-упаковка)
kvsc export examples/heart.kvs -o out.apng           # APNG с альфой
kvsc export examples/heart.kvs -o seq/ --fmt png     # секвенция для ffmpeg
ffmpeg -framerate 60 -i seq/frame_%04d.png -c:v libx264 -pix_fmt yuv420p out.mp4
```

## 4. Веб-плеер

`viewer/server.py` поднимает студию: галерея примеров (обложки берутся из
вшитых в `.kvs` превью), drag&drop своих файлов, покадровая перемотка,
скорость 0.25–2×, инспектор metadанных и живой JSON сцены.
Декодирование — `DecompressionStream`, поэтому сервер отдаёт только байты,
а всю расшифровку делает браузер.

## 5. Проверка согласованности

`tests/parity.js` вычисляет те же каналы на JS, что Python на своих ключах;
тест сверяет значения с точностью 1e-6. Визуально совпадение контролируется
«плёнками» `tools/strip.py`.
