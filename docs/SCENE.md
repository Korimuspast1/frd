# Сцена .kvs: компактная модель и авторинг-формат

Внутри контейнера лежит **компактный JSON**: короткие ключи, массивы вместо
объектов, id-ешники вместо имён easing-кривых. Это даёт файлы в единицы килобайт
(см. `examples/`). Человек пишет анимацию в **авторинг-формате** (длинные ключи,
`examples/src/*.json`) или кодом через `kvs.api`, а компилятор
(`kvs.compile_scene`) переводит одно в другое.

## 1. Компактная сцена

```jsonc
{
  "v": 1,                       // версия схемы сцены
  "nm": "Pulsing Heart",        // имя (опц.)
  "au": "автор", "gn": "kvs-python/1.0",
  "c": {                        // холст
    "w": 512, "h": 512,         // размер, px
    "r": 60.0,                  // fps
    "n": 90,                    // кадров
    "b": "#12001f"              // фон (опц.)
  },
  "a": { "<asset-id>": {...} }, // ассеты: градиенты и переиспользуемые пути
  "l": [ {...слой...}, ... ]    // слои снизу вверх
}
```

### 1.1 Слой

```jsonc
{
  "i": 3,                    // индекс (для parent-ссылок)
  "nm": "heart",             // имя (опц.)
  "hd": 1,                   // скрыт (но матрица всё равно работает для детей)
  "pi": 1,                   // индекс родителя: своя матрица домножается на его
  "b": 0,                    // blend: 0 normal, 1 multiply, 2 screen, 3 overlay, 4 add
  "g": {...} | "<asset-id>", // геометрия
  "f": {...},                // заливка
  "s": {...},                // обводка
  "t": {...}                 // трансформ
}
```

### 1.2 Канал свойства (главная идея формата)

Любое анимируемое значение — **канал**:

```jsonc
100                                  // константа
{"v": 50}                            // константа (явная форма)
{"k": [[0, 0, 18], [22, 112, 18], [45, 96]], "e": 18}
//        ^кадр ^значение ^easing-id   easing по умолчанию
```

* время — в кадрах (дробное можно);
* значение — число, массив чисел (интерполируется покомпонентно),
  строка-цвет (интерполируется в RGB) или список subpath'ов (морфинг);
* easing: id из таблицы (`kvsc codecs`) **или** строковое имя **или**
  `[x1,y1,x2,y2]` — собственная кривая Безье;
* специальное имя `"hold"` держит значение до следующего ключа (резкие удары,
  squash-and-stretch).

Доступные кривые: `linear hold step in/out/in-out × quad cubic quart quint sine
expo circ back elastic bounce`, плюс CSS-совместимые `ease ease-in ease-out
ease-in-out`.

### 1.3 Геометрия `"g"`

| `t`  | примитив     | поля |
|------|--------------|------|
| `p`  | путь Безье   | `s` — список subpath'ов **или канал морфинга** |
| `r`  | прямоугольник| `p` центр, `z` размер |
| `rr` | скруглённый  | + `r` радиус |
| `e`  | эллипс       | `p`, `z` |
| `ci` | круг         | `p`, `r` |
| `pg` | многоугольник| `p`, `n` сторон, `r`, `rot` |
| `st` | звезда       | `p`, `n` лучей, `r1`, `r2`, `rot`, `rd` скругление |

Любое поле может быть каналом (например `r` круга — пульсация).
`ru`: 0 nonzero / 1 evenodd (дырки).

**Subpath** — список точек:

```jsonc
[100, 60]                       // линия до точки
[50, 20, 90, 20, 100, 60]       // кубическая Безье: C c1 c2 p
[50, 20, 100, 60]               // квадратичная: Q c p
[100, 60, 140, 60, 140, 100]    // вершина + исходящая/входящая ручки
0                               // последний элемент: контур НЕ замкнут
```

**Морфинг**: канал, значения которого — списки subpath'ов одинаковой структуры;
движок интерполирует все числа, кривизна плывёт плавно.

### 1.4 Заливка `"f"` и обводка `"s"`

```jsonc
"f": { "c": "#ff3b6b" | {"k":[[0,"#ff0",18],[40,"#0ff"]]},   // цвет (можно канал)
       "g": "<asset-id>" | {...градиент...},                 // либо градиент
       "o": 0.85,                                            // непрозрачность (канал)
       "ru": 0 }
"s": { "c": "#fff", "w": 3, "o": 1,
       "lc": 1,          // cap: 0 butt, 1 round, 2 square
       "lj": 1,          // join: 0 miter, 1 round, 2 bevel
       "ml": 4,          // miter limit
       "d": [24, 12],    // штрих-пунктир (паттерн длин)
       "do": 0 }         // сдвиг штриха (канал) — «бегущий пунктир»
```

### 1.5 Градиенты (ассеты или inline)

```jsonc
{"t":"l", "a":115, "s":[[0,"#ff5f8f"],[0.5,"#c81d55"],[1,"#7a0f3a"]], "u":1}
{"t":"l", "x0":0,"y0":0,"x1":512,"y1":512, "s":[...]}          // явные координаты
{"t":"r", "cx":0.5,"cy":0.42,"r":0.55, "s":[...], "u":1}       // радиальный
{"t":"c", "cx":0.5,"cy":0.5,"a0":0, "s":[...], "u":1}          // конический
```

* `u:1` — координаты нормированы к bbox фигуры (0..1), иначе — локальные координаты слоя;
* `sp`: 0 pad, 1 reflect, 2 repeat;
* градиент «приклеен» к фигуре: при повороте/масштабе слоя он трансформируется вместе с ней.

### 1.6 Трансформ `"t"` (порядок применения — как в After Effects)

```
M = T(p) · R(r) · S(s) · Skew(k) · T(-a)
```

| ключ | смысл | по умолчанию |
|------|-------|--------------|
| `p` | position (куда попадает якорь) | [0,0] |
| `a` | anchor (точка вращения/масштаба) | [0,0] |
| `s` | scale, **в процентах** (100 = 1.0) | [100,100] |
| `r` | rotation, градусы | 0 |
| `k` | skew, градусы | [0,0] |
| `o` | opacity 0..1 (или 0..100) | 1 |

Каждое поле — канал. Иерархия: `"pi"` ссылается на индекс родителя,
мировая матрица = матрица родителя × своя (цепочка до 16 звеньев).

## 2. Авторинг-формат

Тот же смысл, но с человекочитаемыми ключами: `canvas{width,height,fps,frames,
background}`, `layers[{name, geometry{type,...}, fill{color|gradient,opacity},
stroke{color,width,cap,join,dash}, transform{position,scale,rotation,...}, blend,
parent}]`, `assets[{id,type:linear|radial|conic|path,...}]`.
Полные живые примеры — `examples/src/*.json`, построены кодом в `examples/build.py`
через `kvs.api` (`K.animation / K.layer / K.keys / K.morph / K.transform / ...`).

## 3. Минимальный файл целиком

```jsonc
{"v":1,"c":{"w":64,"h":64,"r":30,"n":30,"b":"#101018"},
 "l":[{"i":0,"g":{"t":"ci","p":[32,32],"r":{"k":[[0,4],[15,26,"out-elastic"],[30,4]]}},
       "f":{"c":{"k":[[0,"#ff4d8d"],[30,"#58c7ff"]]}}}]}
```

30 кадров пульсирующего круга: ~150 байт JSON → ~120 байт в контейнере после zlib.
