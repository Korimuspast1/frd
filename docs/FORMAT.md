# KVS — Korium Vector Sequence, версия 1

`.kvs` — самодостаточный контейнер **векторной анимации**: бинарный заголовок +
сжатое JSON-описание сцены + (опционально) вшитое PNG-превью.
Философия близка `.tgs` (Telegram Animated Sticker): маленький файл, вектор внутри,
любой масштаб без потерь. Но формат, теги и движки — полностью собственные.

## 1. Байтовая раскладка

Всё числовые поля — **little-endian**.

| Смещение | Размер | Поле            | Значение |
|---------:|-------:|-----------------|----------|
| 0        | 4      | `magic`         | `4B 56 53 1E` — строка `KVS` + разделитель `0x1E` |
| 4        | 1      | `version`       | `1` |
| 5        | 1      | `flags`         | бит 0–2: кодек; бит 3: есть превью; бит 4–7: резерв = 0 |
| 6        | 2      | `reserved`      | 0 |
| 8        | 2      | `width`         | ширина холста, px (1…65535) |
| 10       | 2      | `height`        | высота холста, px |
| 12       | 2      | `fps`           | частота кадров, **Q8.8** (fps × 256; поддерживает 29.97) |
| 14       | 2      | `frames`        | число кадров (1…65535) |
| 16       | 4      | `payload_size`  | размер сжатого тела, байт |
| 20       | 4      | `payload_crc32` | CRC-32 сжатого тела (контроль целостности) |
| 24       | 8      | `reserved`      | 0 |
| 32       | N      | `payload`       | компактный JSON сцены (см. [SCENE.md](SCENE.md)) |
| 32+N     | M      | `preview`       | PNG-превью первого кадра (только если `flags bit3`) |

Фиксированный заголовок — ровно **32 байта**, поэтому файловые менеджеры и
плееры могут читать метаданные, не распаковывая тело (`kvsc info`).

## 2. Кодеки сжатия (`flags & 0x07`)

| id | кодек  | примечание |
|---:|--------|------------|
| 0  | `raw`  | без сжатия (отладка) |
| 1  | `zlib` | дефолт; поддерживается и браузером (`DecompressionStream("deflate")`) |
| 2  | `gzip` | совместим с утилитами окружения |
| 3  | `lzma` | максимальная степень сжатия (только Python-движок) |
| 4  | `brotli`| зарезервировано (нужна внешняя библиотека) |

Веб-плеер открывает `raw/zlib/gzip`; `lzma/brotli` честно сообщает о недоступности.

## 3. Превью

Если установлен бит 3 флага, после тела идёт обычный PNG (8-bit RGBA).
Превью генерирует компилятор (`kvs.compile_dict(..., preview=True)`) рендером
нулевого кадра в 64 px — галерея показывает обложку, **не распаковывая сцену**.

## 4. Целостность

* `payload_crc32` проверяется при каждом `decode()` (отключается флагом `strict_crc=False`);
* урезанное тело (`payload_size` > остатка файла) → ошибка `KvsError`;
* чужая сигнатура → ошибка с ясным сообщением.

## 5. Время

Кадровая модель: целое число кадров `frames` и `fps` с дробной частью.
Ключевые кадры внутри сцены задаются **в кадрах** (дробные допустимы),
поэтому анимация не зависит от частоты воспроизведения.

## 6. Пример чтения заголовка (Python, stdlib)

```python
import struct
with open("heart.kvs", "rb") as fh:
    magic, ver, flags, _, w, h, fps_q8, frames, size, crc, _ = \
        struct.unpack("<4sBBH HH HH II Q", fh.read(32))
assert magic == b"KVS\x1e"
print(w, h, fps_q8 / 256, frames)
```

## 7. Совместимость и версионирование

* Читатель обязан отвергать `version > 1` (сегодня: 1).
* Неизвестные ключи в JSON-сцене игнорируются движками («robust reading»),
  поэтому будущие расширения не сломают старые плееры.
* Неизвестный кодек → ошибка, а не молчаливая порча кадра.
