# Инструкция для агента

Ты работаешь с репозиторием, где лежит файл `random_10M_chars.txt`. Задача описана в `TASK.md`.

## Правила работы
1. **После каждого действия объясняй, что ты сделал и зачем.** Перед каждой командой напиши, что собираешься сделать. После результата напиши, что получилось и что это значит для следующего шага.
2. Не меняй `random_10M_chars.txt` и не удаляй файлы в репозитории.
3. Не ищи ответ во внешних источниках и не спрашивай пароль у пользователя.
4. Если шаг не сработал, объясни причину и предложи другой подход.

## Что сдать
- Найденный пароль.
- Позицию пароля в файле (номер первого символа, считая с нуля).
- Короткий отчёт: какие шаги сделал, с объяснением каждого.
