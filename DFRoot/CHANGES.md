# Что изменено в этой копии DFRoot

База: [diabl0w/DFRoot](https://github.com/diabl0w/DFRoot), ветка `master` (v4.1, коммит `6de6222`).
Эксплойтная цепочка (`exp.c`, `splicehelper.c`, `libcxx.S`, `bootstrap.c`, `lkm/dfroot.c`) **не тронута** —
все изменения только в UI, диагностике и сборке, чтобы не сломать сам эксплойт.

## Добавлено

| Что | Где |
|---|---|
| **Русская локализация** (вся обёртка: кнопки, меню, настройки, ошибки), английский остался по умолчанию | `res/values/strings.xml`, `res/values-ru/strings.xml` |
| **Диагностика устройства** перед запуском: производитель, модель, Android, патч, ядро, ABI, статус SELinux, состояние root, подходит ли встроенный модуль ядра, предупреждение для 32-бит | `java/df/root/DeviceInfo.java` |
| **Строка состояния** «Root активен / не активен» на главном экране, обновляется при возврате в приложение | `MainActivity` |
| **Сохранение лога** в «Загрузки» через MediaStore (без права на хранилище) — `dfroot-log-<время>.txt` | `java/df/root/LogSaver.java` |
| **Копирование лога** в буфер обмена (для баг-репортов на GitHub/XDA) | `LogSaver.copy()` |
| **Автосохранение лога** после каждого запуска — переключатель в настройках | `preferences.xml`, `MainActivity` |
| **Индикатор прогресса** во время работы эксплойта | `activity_main.xml` |
| **WakeLock** на время прогона, чтобы система не уснула посреди эксплойта (у приложения уже было разрешение `WAKE_LOCK`) | `MainActivity.runExploit()` |
| **Метка времени запуска** в логе (`=== run 2026-10-11 23:41:00 ===`) | `ExploitRunner` |
| **Версия приложения** в подзаголовке и в настройках, пункт «Исходники и обновления» со ссылкой на репозиторий | `MainActivity`, `preferences.xml`, `SettingsFragment` |
| **Понятные объяснения ошибок**: вместо «ERROR — failed to patch files» программа пишет, что именно произошло и что делать (`DEVICE NOT VULNERABLE`, `verification failed`, ошибка ksud, нет SU-менеджера) | `java/df/root/ResultExplainer.java` |
| **Предупреждения совместимости до запуска**: ядро 6.1 (известная «случайная митигация»), нет модуля под ядро, 32-бит; плюс напоминание, если прошлый запуск кончился «не уязвимо» | `java/df/root/Compat.java` |
| **Повторы при неудаче** (0/1/2) с паузой 4 с; если эксплойт сообщил «не уязвимо», повторы не делаются — это бесполезно | `MainActivity`, `preferences.xml` |
| **Уведомление о результате** запуска (канал «Результат DFRoot», разрешение запрашивается на Android 13+) | `MainActivity` |
| Все пользовательские строки вынесены в ресурсы (раньше были хардкодом в Java и XML) | весь `res/`, `ExploitRunner` |

## Исправлено

* `getActionBar()` теперь с проверкой на `null` — раньше падало на темах без ActionBar.
* `findPreference()` для `soft_reboot` / `disable_modules` / `auto_save_log` вынесен в общий метод, они корректно пишутся в device-protected-хранилище (их читает нативный bootstrap).
* Лог в памяти ограничен 256 КБ (раньше он рос бесконечно и мог съесть память при долгих прогонах).

## Сборка

APK собирается в GitHub Actions: `.github/workflows/apk-build.yml` (в корне этого репозитория).
Результат публикуется в папку `out/` этой же ветки.

Сборка подписывается **одноразовым** ключом, сгенерированным прямо в CI (`CN=DFRoot`) —
это не официальная подпись автора, поэтому Android покажет предупреждение при установке,
и обновлять такой APK поверх официального нельзя (подписи не совпадут).
