# Локальная витрина профиля для exteraGram

Плагин `local_visual_profile.py` добавляет **только локальную визуальную имитацию**. Он не выдаёт настоящий Telegram Premium или Stars, не отправляет запросы к Telegram и не меняет серверный профиль, баланс или коллекцию подарков.

## Возможности

- В настройках плагина задаётся любое неотрицательное количество Stars для локального отображения.
- Можно включить локальную метку «Premium» и бейдж на собственном профиле.
- В меню с тремя точками на экране подарка (если версия клиента использует `StarGiftSheet`) появляется пункт **«Добавить в мою локальную витрину»**.
- После добавления бейдж собственного профиля показывает локальный баланс и количество подарков. Нажатие на бейдж или пункт **«Локальная витрина (только у вас)»** в меню профиля открывает список.
- Данные хранятся в настройках плагина отдельно для каждого аккаунта на этом устройстве. Максимум — 500 локальных записей подарков.

Это отдельная витрина плагина, а не настоящая коллекция Telegram: другие пользователи её не увидят. В интерфейсе витрина помечена как локальная, чтобы её нельзя было принять за серверные данные.

## Установка

1. Используйте exteraGram с включённой системой плагинов (ориентир SDK: exteraGram 12.5.1+).
2. Скачайте `local_visual_profile.py` на телефон или отправьте файл в «Избранное».
3. Откройте файл в exteraGram и установите его через менеджер плагинов.
4. В **Настройки → Плагины → Локальная витрина профиля** укажите визуальное количество Stars и, при желании, включите метку Premium.
5. Откройте маркет подарков, зайдите на экран подарка и нажмите три точки. Выберите **«Добавить в мою локальную витрину»**.
6. Вернитесь в собственный профиль. Локальный бейдж появится там; нажмите его, чтобы посмотреть список.

Если пункт в меню подарка не появился, вероятно, сборка клиента изменила внутренний класс экрана подарка. Настройки и локальная витрина профиля при этом остаются доступны; hooks сделаны необязательными и не должны ломать загрузку плагина.

## Проверки

```bash
python3 -B - <<'PY'
from pathlib import Path
compile(Path('local_visual_profile.py').read_text(encoding='utf-8'), 'local_visual_profile.py', 'exec')
print('syntax OK')
PY
```
