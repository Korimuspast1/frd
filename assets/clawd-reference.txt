The default terminal mascot is constructed from these Unicode block glyphs:
 ▐▛███▜▌
▝▜█████▛▘
  ▘▘ ▝▝

Foreground clawd_body: rgb(215,119,87), #d77757
Background clawd_background: rgb(0,0,0)
The film rasterizes these glyphs into a pixel mask, rather than inventing
another character. The silhouette, eyes/negative space, four legs and
body colour are preserved. Terminal glyph aspect ratio is 1:2.
No CLI executable or source code is redistributed.
