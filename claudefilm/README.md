# Claude Code: ночная работа

Неофициальный короткий 3D-ролик про Claude Code от Anthropic и его пиксельного персонажа. История: работа над проектом, исчерпание лимита и перерыв на кофе.

- `claude_code_3d_sound.mp4` — готовое видео со звуком (18 секунд).
- `claude_scene.blend` — редактируемая сцена Blender: модели, материалы, источники света и анимация камеры.
- `scene.py` — скрипт создания и покадрового рендера сцены при наличии модуля `bpy`.
- `finish.py` — сборка ролика, титров и оригинального синтезированного звукового сопровождения (Python, Pillow, NumPy и imageio-ffmpeg).

Скрипты используют временные пути `/home/user/claude_frames` и `/home/user/claude_audio.wav`. Рендерит каждый второй кадр анимации, а при сборке добавляются промежуточные кадры.

## Продолжение: зомби-апокалипсис

- `claude_zombie_apocalypse.mp4` — 40-секундный ролик с двумя озвученными персонажами, музыкой и эффектами.
- `zombie_apocalypse.blend` — сцена Blender с зомби, анимацией и тревожным освещением.
- `zombie_scene.py` и `zombie_finish.py` — создание сцены и монтаж; запись голосов находится в `voice/`.

Кадры рендерятся в `/home/user/zombie_frames` с шагом в три кадра, при монтаже используются промежуточные кадры для видео 12 кадров в секунду. Для скриптов требуются `bpy`, Pillow, NumPy и imageio-ffmpeg.
