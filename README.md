# frd

Репозиторий с проверкой на вирусы и с доработанной сборкой [DFRoot](https://github.com/diabl0w/DFRoot).

## Что где лежит

| Путь | Что это |
|---|---|
| `AUDIT.md` | **Отчёт о проверке на вирусы** — по `PaxUniverseSetup.exe` и по исходникам DFRoot. Читайте первым. |
| `PaxUniverseSetup.exe` | Исходный файл репозитория. Проверен: **чистый**, это установщик игры Pax Universe (Godot). Не удалял — вредоносного кода нет. |
| `DFRoot/` | Исходники DFRoot (инструмент получения root на Android через CVE-2026-43284) с моими доработками. |
| `DFRoot/CHANGES.md` | Список доработок: что добавлено и что исправлено. |
| `.github/workflows/apk-build.yml` | Сборка APK в GitHub Actions (LKM для 8 версий ядра + APK). |
| `out/` | Готовые APK, CI публикует их сюда автоматически. |

## Коротко про проверку на вирусы

* `PaxUniverseSetup.exe` — **вирусов не найдено**. SHA-256 `998f8c84f1dbf0876b558472dbda56da2e7e20b993d96f776ff2c92977552c96`.
  Это .NET/WPF-установщик: качает `manifest.json` с `paxuniverse.ru` и GitHub, проверяет SHA-256 файлов,
  ставит игру в `%LOCALAPPDATA%\Programs\PaxUniverse`, создаёт ярлыки и запись в «Установка и удаление программ».
  Никаких P/Invoke, инжектов, автозапуска, запроса прав администратора и обращений на левые домены.
  Единственный минус — **нет цифровой подписи**, поэтому Windows покажет SmartScreen.
* DFRoot — **бэкдоров и вирусов в исходниках нет** (проверено построчно), но это эксплойт-инструмент:
  любой антивирус и Play Protect задетектят APK как `Android/Exploit` / «Rooting tool».
  Подробности — в `AUDIT.md`.

| Файл | Размер | SHA-256 |
|---|---|---|
| `out/DFRoot-release.apk` | 91.8 КБ | `894c032aa0fa5e309b94a86c941b57e6e06369b342bcccda91e1b42889a46994` |
| `out/DFRoot-debug.apk` | 2.51 МБ | `9aad022eb8e0b5daf92cc2da63d0d6d68890cb9e092f033d7daa264cfc4d185f` |

* Оба подписаны (APK Signature Scheme v2/v3).
* Ставьте **release** — он минифицирован R8 и почти такого же размера, как официальный (80 КБ).
* Debug-версия нужна только если хочется смотреть полные логи без обрезки; она тянет за собой
  kotlin-stdlib из AGP (поэтому и 2.5 МБ) и пригодна только для отладки.

## Как собрать APK

Вручную (нужен JDK 21 + Android SDK 37 + NDK или podman для LKM):

```bash
cd DFRoot
make            # соберёт keystore.jks, все .ko и out/DFRoot.apk
```

Автоматически — пуш в ветку `arena/**` или кнопка **Run workflow** в Actions.
Готовый APK появляется в `out/` и в артефактах прогона (`DFRoot-APK`).

> APK из `out/` подписан **одноразовым** ключом (`CN=DFRoot`), а не ключом автора.
> Это нормально для тестов, но поверх официального DFRoot он не установится — подписи разные.

## Дисклеймер

DFRoot — инструмент получения root через уязвимость ядра. Используйте **только на своём устройстве**:
отключается SELinux, следит гарантия, перестают работать банковские приложения, возможен бутлуп.
