# Искра AI — чат с веб-поиском для Android

Нативное Android-приложение с современным интерфейсом чата, локальной историей и ответами на основе интернет-источников. По умолчанию оно работает **бесплатно и без API-ключа**: ищет материалы через открытые веб-интерфейсы Bing RSS и Wikipedia, формирует краткий ответ и показывает ссылки.

При желании можно включить настоящую нейросеть через любой OpenAI-совместимый API:

- OpenRouter;
- локальные Ollama или LM Studio;
- собственный сервер;
- другой совместимый провайдер.

## Что уже работает

- создание, просмотр, поиск, переименование и удаление чатов;
- автоматическое название диалога по первому вопросу;
- постоянная история в локальной SQLite-базе;
- бесплатный веб-поиск без регистрации;
- карточки источников под ответом;
- подключение AI с контекстом веб-поиска;
- история из последних сообщений для продолжения разговора;
- копирование и отправка ответов;
- повтор неудачного запроса;
- шифрование API-ключа через Android Keystore;
- поддержка Android 8.0+ (API 26).

## Установка

Готовый APK находится в [`out/IskraAI-release.apk`](out/IskraAI-release.apk) после успешной сборки. На телефоне нужно разрешить установку приложений из выбранного браузера или файлового менеджера.

> APK подписан временным ключом автоматической сборки и предназначен для личной установки/тестирования. Для публикации в магазине следует настроить постоянный приватный release-ключ.

## Режимы ответа

### Веб-поиск (по умолчанию)

Работает сразу. API-ключ не нужен. Приложение отправляет текст вопроса поисковым сервисам, показывает краткую выдержку и источники. Это извлекающий режим, поэтому он не притворяется нейросетью и не должен придумывать отсутствующие факты.

### AI + интернет

1. Откройте **Настройки**.
2. Включите **Использовать нейросеть**.
3. Для OpenRouter оставьте адрес `https://openrouter.ai/api/v1`, модель `openrouter/free` и вставьте свой ключ.
4. Сохраните настройки.

Результаты веб-поиска будут переданы модели как контекст. Ключ хранится зашифрованным в Android Keystore и не записывается в репозиторий.

### Локальная скачанная модель

Запустите Ollama или LM Studio на компьютере в той же Wi‑Fi сети, разрешите подключение из локальной сети и укажите, например:

- API: `http://192.168.1.2:11434/v1`
- модель: имя установленной в Ollama модели
- API-ключ: можно оставить пустым

Адрес `localhost` в приложении означает сам телефон, поэтому нужно использовать локальный IP компьютера.

## Сборка

Нужны JDK 21 и Android SDK с API 37:

```bash
./gradlew :app:assembleDebug
```

Release APK автоматически собирается GitHub Actions workflow `Build Iskra AI APK`. Сторонних Android-библиотек нет, поэтому итоговый APK остаётся небольшим.

## Приватность

Чаты хранятся на устройстве. Для ответа текст запроса отправляется выбранным поисковым сервисам и, если включён AI, выбранному AI-провайдеру. В приложение не встроены чужие API-ключи, реклама или аналитика.
