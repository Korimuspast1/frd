# OpenCode Android (`v2.2.5`)

Полный рабочий порт **[anomalyco/opencode](https://github.com/anomalyco/opencode)** на Android с архитектурой **1-в-1 как на ПК**: фоновый демон-сервис, создание и управление локальными проектами, чтение/создание/редактирование/удаление файлов, патчи, откаты по снимкам (`revert`), встроенный терминал Android Shell, все фирменные темы OpenCode (`OC-2`, `AMOLED`, `Tokyo Night`, `Catppuccin`, `Cursor`, `Aura`) и поддержка всех облачных/локальных AI-провайдеров + подключения к `opencode serve` на ПК.

> *Примечание в соответствии с правилами бренда OpenCode: это независимый открытый порт на платформу Android, не аффилированный напрямую с командой Anomaly / OpenCode.*

---

## Готовый установочный файл APK

- **`OpenCode-Android-v2.2.5.apk`** (в корне репозитория и в `opencode-android/dist/OpenCode-Android-v2.2.5.apk`)
- **Package ID:** `ai.opencode.android`
- **Android SDK:** `minSdk 26` (Android 8.0+) — `targetSdk 34` (Android 14/15/16)
- **Подпись APK:** `APK Signature Scheme v1 + v2 + v3` (готов к прямой установке на любой смартфон или планшет Android)

## Что реализовано (1-в-1 как в десктопном OpenCode)

1. **Нативный фоновый сервис Android (`OpenCodeDaemonService.kt` + `LocalHttpDaemon.kt`)**
   - Запускается как полноценный Android `ForegroundService` с системным уведомлением и управлением `Partial WakeLock` во время активной работы агента — задачи, потоковая генерация кода и shell-команды не обрываются при сворачивании приложения или блокировке экрана.
   - Поднимает локальный многопоточный демон `127.0.0.1:<port>` со встроенным потоковым прокси (`HttpURLConnection`), устраняющим любые ограничения CORS при обращении к API провайдеров и локальным серверам.

2. **Локальные проекты и полная работа с файлами (`WorkspaceManager.kt`)**
   - Создание локальных проектов по шаблонам (`TypeScript/Web`, `Python`, `Kotlin/Android`, пустой проект).
   - **Прямое клонирование репозиториев с GitHub** по ссылке `https://github.com/owner/repo` прямо на телефон (даже без установленного `git`).
   - Экспорт любого проекта в `.zip` через системное меню «Поделиться» (`OpenCodeFileProvider`).
   - Встроенный проводник и редактор кода с подсветкой изменений (`+добавлено / -удалено`), созданием папок и файлов, переименованием, редактированием и удалением.
   - Система снимков сессии (**Snapshots & Revert**): перед каждым запросом фиксируется состояние проекта — можно откатить все файлы к любому сообщению одной кнопкой.

3. **Полный набор инструментов агента OpenCode (`build`, `plan`, сабагент `@general`)**
   - `read` — чтение файлов с нумерацией строк и диапазонами.
   - `write` — создание и перезапись файлов с генерацией unified diff.
   - `edit` — точечная замена кода с проверкой вхождения и diff.
   - `apply_patch` — мультифайловые патчи формата `*** Begin Patch` (`Add`, `Delete`).
   - `delete_file` — удаление файлов и директорий (с возможностью отката через Snapshot).
   - `glob` и `grep` — быстрый поиск файлов по маске и регулярным выражениям по всему проекту.
   - `bash` — выполнение реальных команд `/system/bin/sh` в папке проекта на Android (`ShellExecutor.kt`, с автоподхватом путей Termux при наличии).
   - `todowrite` / `todoread` — интерактивный чек-лист задач сессии.
   - `webfetch` — загрузка и очистка веб-страниц для контекста агента.
   - `question` — интерактивные карточки уточняющих вопросов прямо в чате.
   - `task` — делегирование подзадач автономному сабагенту `@general`.

4. **Мульти-провайдер AI + Автономный тест-движок + Связка с ПК**
   - Поддержка **Anthropic (Claude)**, **OpenAI**, **Google Gemini**, **OpenRouter** (включая бесплатные `:free` модели), **DeepSeek**, **Groq**, **xAI (Grok)** и **Ollama / локальных моделей**.
   - Встроенный автономный тест-движок для мгновенной проверки чтения/создания/удаления файлов и терминала сразу после установки APK без ввода ключей.
   - Режим подключения к удалённому серверу `opencode serve` на ПК (по IP/URL, паролю или ссылке сопряжения).

## Сборка и запуск из исходников

```bash
cd opencode-android
npm install

# Сборка веб-ядра и компиляция подписанного Android APK:
npm run build:apk

# Запуск локального сервера живого превью (порт 4096):
npm run start
```

Для открытия нативной части в **Android Studio** откройте каталог `opencode-android/android`.
