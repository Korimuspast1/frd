# Beepnook — Gadget Shop (нативная C++ версия, без Unity и без браузера)

Полная переработка главного меню по твоему референсу на чистый C++.  
**Не HTML, не браузер, не Unity.** Компилируется обычным `g++` в нативный бинарный файл, который запускается в терминале.

Тема изменена: это **магазин гаджетов (Gadget Shop)**, не ремонтная мастерская.

## Что внутри

```
src/main.cpp      — исходный код игры (меню + магазин + день)
Makefile          — сборка через make
build.sh          — быстрая сборка одной командой
beepnook          — скомпилированный бинарный файл (уже готов к запуску)
```

## Сборка

```bash
cd /home/user/frd
make
# или
./build.sh
```

Получится файл `beepnook` — нативный бинарник.

## Запуск

```bash
./beepnook
```

Управление:
- Стрелки / WASD — выбрать пункт меню
- Enter — подтвердить
- Q — выход

Меню:
- **Continue** —进入 игру (день 1)
- **New game** — новая игра (день 1, деньги $500)
- **Settings** — заглушка
- **How to play** — справка
- **Credits** — авторы
- **Exit** — выход

В игре:
- 1 — пополнить склад ($50 за товар)
- 2 — открыть магазин на день (продажа гаджетов, заработок)
- 3 — вернуться в меню

## Требования

- g++ (любой современный)
- Linux / macOS терминал с поддержкой ANSI-цветов

## Почему нет APK

Для настоящего Android APK требуется Android SDK + NDK, которых нет в этой среде.  
Этот бинарник работает нативным образом на Linux/macOS. Если нужен APK — собери тот же код под Android через Android Studio (NDK) или используй исходник как базу для портирования.
