# Local Visual Profile для exteraGram

Локальный exteraGram-плагин для визуальной витрины профиля: условный баланс Stars, локальная метка Premium и выбранные подарки. Все значения хранятся в настройках плагина на устройстве и не отправляются в Telegram.

> **Важно:** это не выдаёт настоящий Premium или Stars и не изменяет серверный профиль либо официальную коллекцию подарков. Витрина помечена как локальная и видна только в этом клиенте.

## Файлы

- [`local_visual_profile.py`](./local_visual_profile.py) — устанавливаемый файл плагина.
- [`LOCAL_VISUAL_PROFILE.md`](./LOCAL_VISUAL_PROFILE.md) — установка, сценарий использования и ограничения.

## Быстрый старт

1. Установите актуальный exteraGram с поддержкой плагинов.
2. Передайте `local_visual_profile.py` на телефон и откройте его в exteraGram.
3. Установите и включите плагин через менеджер плагинов.
4. В настройках плагина задайте локальное количество Stars и, при необходимости, включите метку Premium.
5. В меню подарка нажмите **«Добавить в мою локальную витрину»**. В своём профиле нажмите на бейдж, чтобы открыть сохранённые записи.

Подробная инструкция и условия совместимости: [`LOCAL_VISUAL_PROFILE.md`](./LOCAL_VISUAL_PROFILE.md).
