# kvsai — Android-чат с AI, интернетом и данными устройства

Нативное приложение для Android 8.0+ с чатами, веб-поиском, подключаемой нейросетью, актуальной погодой и локальными сведениями об устройстве.

## Возможности

- минималистичный near-black интерфейс с матовым glass-эффектом, светящимся ассистентом и плавными переходами;
- создание, поиск, переименование и удаление чатов в выдвижной панели;
- анимация разрушения видимой карточки перед окончательным удалением чата;
- голосовой ввод и опциональная автоозвучка ответов системным голосом;
- режим глубокого рассуждения с анимированным индикатором проверки и кратким объяснением вывода;
- живой счётчик токенов: промежуточная оценка помечается `≈`, а данные провайдера — как точные;
- маленький анимированный спутник, который ненавязчиво реагирует на ввод текста;
- анализ вложений размером до 66 МБ: фотографий, первых страниц PDF и текста из TXT/Markdown/JSON/CSV, DOCX, PPTX, XLSX, ODT и файлов с кодом;
- постоянная идентичность kvsai, созданной kvsai org, с несколькими естественными вариантами ответа на вопрос «кто ты?»;
- сохранение истории в локальной SQLite-базе;
- бесплатный веб-поиск через Bing RSS и Wikipedia;
- OpenAI-совместимые провайдеры: OpenRouter, Ollama, LM Studio и другие;
- актуальная погода на сегодня, завтра и послезавтра через Open-Meteo без API-ключа;
- ответы о текущем времени, модели телефона, Android, CPU, ОЗУ, хранилище, экране и заряде;
- Markdown и отдельные fenced-блоки кода для любого языка;
- подсветка Python, Java, Kotlin, JS/TS, C/C++, C#, Go, Rust, SQL, Bash, JSON, HTML/XML, CSS и других языков;
- горизонтальная прокрутка и отдельная кнопка копирования кода;
- шифрование API-ключа через Android Keystore.

## APK

Готовая сборка публикуется в [`out/kvsai-release.apk`](out/kvsai-release.apk). APK использует стабильный публичный AOSP test key: он подходит для личной установки и обновлений тестовых версий, но не для публикации в магазине.

Приложение теперь имеет package id `app.kvsai.chat`, поэтому устанавливается отдельно от старой сборки «Искра AI».

## Погода

Примеры запросов:

- `Какая погода завтра в Москве?`
- `Будет ли дождь сегодня в Риге?`
- `Прогноз послезавтра во Владивостоке`

Город преобразуется в координаты через Open-Meteo Geocoding API, после чего приложение получает реальный ежедневный прогноз.

## Данные устройства

Примеры:

- `Сколько сейчас времени?`
- `Что за модель телефона?`
- `Покажи характеристики моего устройства`
- `Какой уровень заряда?`

Приложение использует только обычные Android API. IMEI, серийный номер и другие закрытые идентификаторы не считываются.

## Подключение AI

1. Откройте **Настройки**.
2. Включите **Использовать нейросеть**.
3. Для OpenRouter оставьте `https://openrouter.ai/api/v1`, укажите модель и API-ключ.
4. Для локальной модели укажите адрес Ollama/LM Studio в Wi-Fi сети, например `http://192.168.1.2:11434/v1`.

Системная инструкция требует от модели оформлять любой многострочный код как Markdown-блок с языком, а обычный код без синтаксиса — как `plaintext`.

## Фото и документы

Нажмите `＋` рядом с полем ввода и выберите фотографию или файл через системное окно Android. Общий доступ к хранилищу не запрашивается. Текст и уменьшенные изображения готовятся локально; отправка содержимого происходит только при включённой AI-модели. Для фотографий и PDF нужна модель с поддержкой vision.

## Защита release-сборки

Release-вариант минифицируется и обфусцируется R8, отключает резервное копирование, отклоняет отладчик и при запуске проверяет package id, сертификат подписи и обязательные части APK. Android дополнительно проверяет криптографическую подпись APK при установке. API-ключ хранится через AES-GCM в Android Keystore.

Абсолютно «невзламываемого» клиентского APK не существует: код, выполняющийся на чужом устройстве, теоретически можно исследовать и переписать. Эти меры являются защитой в несколько слоёв и заметно усложняют обычную модификацию, но не заменяют Play Integrity и серверную проверку для высокорискового продукта. Текущая тестовая сборка подписывается публичным AOSP test key; для настоящего production-релиза его нужно заменить закрытым ключом, хранящимся только в секретах CI.

## Сборка

Нужны JDK 21 и Android SDK API 37:

```bash
./gradlew :app:assembleDebug
```

GitHub Actions автоматически собирает debug/release APK, проверяет сборку и публикует release-файл в `out/`.
