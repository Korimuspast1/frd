# Приватность kvsai

- История чатов хранится локально в SQLite на устройстве.
- API-ключ шифруется ключом из Android Keystore и исключён из резервной копии.
- В приложении нет рекламы, трекеров и аналитики.
- В режиме веб-поиска текст запроса отправляется Bing и Wikipedia.
- Запросы погоды и название города отправляются Open-Meteo.
- При включённой нейросети вопрос, недавняя история и найденные выдержки отправляются указанному пользователем AI-провайдеру.
- Данные модели устройства, памяти, экрана и батареи читаются локально и сами по себе никуда не отправляются. Если пользователь вставляет их в сообщение, это сообщение обрабатывается как обычный запрос.
- Debug mode хранит журнал только в памяти процесса. В журнал попадают действия приложения, текст запросов, URL, статусы и ошибки; API-ключ и Authorization скрываются. Журнал можно очистить или скопировать вручную.
- IMEI, серийный номер и другие закрытые идентификаторы не запрашиваются.
- Историю можно удалить в настройках приложения или через системную очистку данных.
