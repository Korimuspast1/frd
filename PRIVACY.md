# Приватность kvsai

- История чатов хранится локально в SQLite внутри закрытого хранилища приложения. Системное резервное копирование приложения отключено.
- API-ключ шифруется ключом из аппаратно защищённого Android Keystore.
- В приложении нет рекламы, трекеров и аналитики.
- В режиме веб-поиска текст запроса отправляется Bing и Wikipedia.
- Запросы погоды и название города отправляются Open-Meteo.
- При включённой нейросети вопрос, недавняя история и найденные выдержки отправляются указанному пользователем AI-провайдеру.
- Фотография или файл открываются только после явного выбора в системном окне Android. Приложение не запрашивает общий доступ ко всему хранилищу.
- Текстовые документы разбираются локально, изображения уменьшаются локально, а PDF локально преобразуется максимум в четыре изображения страниц. При включённой AI-модели подготовленное содержимое выбранного вложения отправляется этому AI-провайдеру для анализа. При выключенной модели файл никуда не отправляется.
- Исходное вложение и его копия не сохраняются в базе чатов; в истории остаются только название вложения, вопрос и ответ.
- Данные модели устройства, памяти, экрана и батареи читаются локально и сами по себе никуда не отправляются. Если пользователь вставляет их в сообщение, это сообщение обрабатывается как обычный запрос.
- Debug mode хранит журнал только в памяти процесса. Журнал содержит маршруты функций, размеры данных, URL, HTTP-статусы, длительность и ошибки, но не текст вопросов, содержимое файлов, API-ключ или Authorization. Журнал можно очистить или скопировать вручную.
- IMEI, серийный номер и другие закрытые идентификаторы не запрашиваются.
- Историю можно удалить в настройках приложения или через системную очистку данных.
