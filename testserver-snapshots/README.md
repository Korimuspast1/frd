# Локальный просмотрщик снапшотов тестовых серверов Telegram

Один файл на чистом Python 3 (без зависимостей), который поднимает веб-интерфейс
над архивом [glebxdlolreal/testserverchangesall](https://github.com/glebxdlolreal/testserverchangesall) —
слепками веб-ресурсов пяти поддоменов тестового сервера Telegram (`a-`, `b-`, `i-`, `l-`, `y-`)
и ответов MTProto-методов (`help.getConfig`, `wallet.getCurrencyRates` и т.д.).

## Установка

Ничего устанавливать не нужно — только клонировать данные и запустить скрипт.

```bash
git clone https://github.com/glebxdlolreal/testserverchangesall.git ~/testserverchangesall
python3 server.py
# → http://localhost:8000
```

Переменные окружения:

| Переменная      | По умолчанию                        | Что делает              |
| --------------- | ----------------------------------- | ----------------------- |
| `SNAPSHOT_ROOT` | `/home/user/testserverchangesall`   | каталог со снапшотами   |
| `PORT`          | `8000`                              | порт                    |
| `HOST`          | `0.0.0.0`                           | адрес для bind          |

## Маршруты

| Путь                        | Что отдаёт                                                   |
| --------------------------- | ------------------------------------------------------------ |
| `/`                         | главная: карточки поддоменов, JSON-методы, кнопка обновления |
| `/{sub}/`                   | список файлов поддомена: страницы, css/js, размер, история   |
| `/{sub}/botfather.html`     | страница снапшота с панелью просмотра                        |
| `/{sub}/css/...`, `/js/...` | ресурсы из плоского каталога поддомена                       |
| `/raw/{sub}/{file}`         | исходный файл без перезаписи                                 |
| `/json/{method}.json`       | JSON-снапшот метода с подсветкой                             |
| `/history/{sub}/{file}`     | `git log` по файлу                                           |
| `POST /api/pull`            | `git pull --ff-only` + переиндексация истории                |

## Как это работает

* Страницы снапшота ссылаются на ресурсы абсолютными путями корня домена
  (`/css/bootstrap.min.css`, `/js/botfather.js`, `/img/favicon.ico`).
  Сервер переписывает их в `/{sub}/...`, а плоский каталог поддомена
  (`y-/botfather.css`) отдаётся под запрошенным путём (`/y-/css/botfather.css`)
  с перезаписью `url(...)` внутри CSS.
* `/img/*` в архив не попадает — вместо картинок отдаётся прозрачный GIF 1×1,
  чтобы вёрстка не «прыгала» от битых ссылок.
* История изменений строится **одним** проходом по `git log --name-only`
  и кладётся в индекс при старте (3893 коммита ≈ 3 с).
* В каждую HTML-страницу вставляется панель: «← все снапшоты», поддомен,
  история, исходник, скрыть панель.

## Ограничения

Это архив слепков, а не работающее приложение. Формы и AJAX-запросы к
`*.telegram.org` не выполнятся: в этой среде нет доступа к серверам Telegram,
а в снапшоте нет ни авторизационных токенов, ни `sig=`/`se=` (репозиторий их
специально вычищает при нормализации). Смотреть можно разметку, стили, скрипты
и содержимое JSON-ответов.

## `PaxUniverseSetup.exe`

В корне этого репозитория лежит `PaxUniverseSetup.exe` — .NET Framework 4.8
WPF-установщик («Pax Universe»), который при запуске читает манифест с
`paxuniverse.ru` и ставит приложение в `%LOCALAPPDATA%\Programs`. Запустить его
здесь нельзя: окружение Linux без Wine, а `paxuniverse.ru` вне списка разрешённых
хостов. Он не связан со снапшотами Telegram и в этом просмотрщике не используется.
